# HLS illustrations

Full-bleed cover-background photography, optimized for the web (resized to a
2400px long edge, JPEG). Uploaded originals were 4500×2531–4500×2622 PNGs
totaling ~165MB; these are the same images resized and compressed, ~8.3MB
total, since a deliverable has to stay reasonably sized to zip or email.
Licensed stock photography (Adobe Stock, per embedded IPTC credit on at
least one file) — confirm the license covers redistribution through this
plugin before shipping a deliverable that uses one externally.

| File | Stock caption | Vertical fit |
|---|---|---|
| `healthcare-molecules-01-{horizontal,vertical}.jpg` | "Transparent blue abstract molecule model over blurred blue molecule background... science, chemistry, medicine" | Healthcare / clinical / provider-payer |
| `healthcare-stethoscope-01-{horizontal,vertical}.jpg` | "A stethoscope shaping a heart and a clipboard on a medical uniform, closeup" | Healthcare / clinical / provider-payer |
| `life-sciences-macro-01-{horizontal,vertical}.jpg` | "Red strawberry anemones with tentacles fully exposed..." | Life sciences — biological/environmental research, not pharma-specific |
| `life-sciences-macro-02-{horizontal,vertical}.jpg` | "Aerial view of greenhouse area with vegetables" | Life sciences — agricultural (agtech/crop science) |

"HLS" spans more than clinical/pharma — see [overview.md](../../references/overview.md)
for how this pack scopes the life-sciences half of the vertical (it
includes agriculture and broader biological/environmental research, not
just pharma/biotech/medtech). Pick whichever pair actually matches the
engagement: `healthcare-*` for a provider/payer/clinical context,
`life-sciences-macro-01-*` for biological/environmental research,
`life-sciences-macro-02-*` for an agricultural/agtech one.

Reference one directly for a cover via `meta.cover_background` in authored
content — see [../../references/deliverable-guidance.md](../../references/deliverable-guidance.md) for exactly how.
