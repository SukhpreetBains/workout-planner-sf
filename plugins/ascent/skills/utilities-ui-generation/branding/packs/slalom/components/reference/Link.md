# Link

An inline link in the `link` color: Slalom Blue on white, white and underlined on black. The underline appears on hover and focus in Light and is always on in Dark, so a link never depends on color alone. Write link text that says where it goes, never "click here".

## Markup

```html
<p class="body">Read <a class="sl-link" href="#">how we approach data strategy</a>.</p>
```
