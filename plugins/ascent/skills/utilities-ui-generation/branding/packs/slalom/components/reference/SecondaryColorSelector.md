# SecondaryColorSelector

The four secondary colors in one swatch row, with the same magnify, hex tooltip and click-to-copy as `ColorSelector`. Use it where a maker picks the composition's one secondary color: brand pages, template pickers, internal tools. For one color's tones and tints, list that family's seven tokens in `data-tokens` instead.

## Markup

```html
<div data-sl="color-selector" data-name="Secondary" data-tokens="cyan coral-red purple chartreuse"></div>
```
