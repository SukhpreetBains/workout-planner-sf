# Headline

An eyebrow, a headline and a dek, flush left. Size with `headline-xl`, `headline-xl-black` (a short message that needs force), `headline-l` or `headline-m`. Sentence case always; an eyebrow is a short label, the only place all caps belongs. Check line breaks for widows and hyphenated ends.

## Markup

```html
<header class="sl-headline">
  <p class="sl-eyebrow eyebrow">Our approach</p>
  <h2 class="sl-headline-text headline-l">Better tomorrows, built together</h2>
  <p class="sl-dek body">We help people and organizations dream bigger, move faster, and build better tomorrows for all.</p>
</header>
```
