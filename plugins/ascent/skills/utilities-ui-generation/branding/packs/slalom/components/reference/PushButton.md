# PushButton

A chunky block button: white face, 6px Slalom Blue border and Slalom Dark Blue label on a solid 8px Slalom Dark Blue base that it drops onto when pressed. Add `sl-push-pill` for the pill silhouette. Inverts on `data-theme="dark"`. After Uiverse `KhelVers/orange-lionfish-62` (MIT).

The base is a solid block, not a soft shadow; never blur it. Use it for playful, high-energy moments (events, campaigns, internal tools), one or two per view. `Button` stays the default.

## Markup

```html
<button type="button" class="sl-push">Join the session</button>
```
