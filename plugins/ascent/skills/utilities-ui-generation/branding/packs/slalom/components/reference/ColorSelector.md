# ColorSelector

The brand palette as a dock of swatches: hover magnifies a swatch and shows its token and hex; click copies the hex. Leave `data-tokens` off for the full palette (primaries, each secondary's tones and tints, neutrals), or list token names for one row with a `data-name` label (see `SecondaryColorSelector`). After Uiverse `Cobp/horrible-quail-18` (MIT).

A reference tool for brand pages, template pickers and handoff portals, not a product control: showing every brand color together is otherwise reserved for infographics and the color bar.

## Markup

```html
<div data-sl="color-selector"></div>
```
