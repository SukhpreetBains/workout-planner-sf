# Checkbox

A 24px square with a 2px ink border that fills Slalom Blue with a white check when checked. Native checkbox underneath. Use it for multi-select choices and consents; corners stay square.

## Markup

```html
<label class="sl-check"><input class="sl-check-input" type="checkbox" checked><span class="sl-check-box" aria-hidden="true"></span><span class="sl-check-label body">Include appendix</span></label>
```
