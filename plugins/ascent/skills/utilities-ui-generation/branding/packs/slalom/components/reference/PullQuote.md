# PullQuote

A quotation with its attribution and a 2px Slalom Blue rule. Everything is Slalom Sans: Lora, the guide's optional quote serif, is not bundled, so disclose the substitution when a serif is expected. Quote real people, with consent and real titles. The name above is a placeholder.

## Markup

```html
<figure class="sl-quote">
  <blockquote class="sl-quote-text quote">“They listened first. The plan felt like ours from day one.”</blockquote>
  <figcaption class="sl-quote-by"><span class="sl-quote-name quote-name">Sam Okafor</span><span class="sl-quote-title quote-title">Chief people officer</span></figcaption>
</figure>
```
