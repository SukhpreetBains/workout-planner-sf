# Slalom Branding

The default branding pack. Applies Slalom brand styling and voice
across deliverables, including PowerPoint decks, PDFs, Word
documents, spreadsheets, one-pagers, status reports, diagrams,
screenshots, portals, dashboards, and web experiences.

## Quick Start

1. Identify the medium first — it decides the typeface and little else transfers between media.
2. Read only the reference files the task touches. Each is single-topic and short.
3. Take artwork from `../assets/`, never from an outside set.
4. Check the result against the non-negotiables below, or `review-checklist.md` for a full review.

## Non-negotiables

These hold everywhere. Everything else is in the references.

- **A Slalom Blue** — `#0C62FB` or Slalom Dark Blue `#002FAF` — appears in every composition, paired with at most one secondary color.
- **Avenir Next LT Pro is PowerPoint-only**, plus Outlook defaults, Power BI, and editable Word docs shared with customers. Everything else uses Slalom Sans, with Lora optional.
- **Sentence case**, flush left, ragged right.
- **The logo appears only in Slalom Blue, Slalom Dark Blue, White, or Black**, unaltered, with clear space of at least the width of an "o."
- **Never invent a logo, mark, icon, or illustration.** Use the approved assets or request new ones.
- **Text, charts, and data graphics meet WCAG 2.1 AA**, and nothing communicates through color alone.
- **"Fiercely human" stays intact and stays a descriptor.** Never split it, never call anything "fierce," never imply Slalom makes people more human.

## Assets

- `../assets/logos/` — the wordmark in all four approved colors.
- `../assets/iconography/` — 102 approved icons, indexed in its README.
- `../assets/illustrations/` — 116 people illustrations across 37 subjects, indexed in its README.
- `../assets/color-bars/` — reference artwork for the framing and underline bars.
- `../assets/fonts/` — Slalom Sans (10 styles, woff2/woff/otf), indexed in its README. Self-host from here for web and digital work. Avenir Next LT Pro is not bundled by design — it is PowerPoint-only. Lora, the optional supporting serif, is not bundled either, so anything needing a serif must be composed in Slalom Sans and the substitution disclosed.
- `../components/` — 32 framework-free HTML/CSS/JS patterns for web deliverables (`slalom-components.css`, `slalom-components.js`), with a live `gallery.html` and one reference file per pattern. They use only the tokens, fonts and assets above.
- `../assets/branding-guide/Slalom Brand Guide.pdf` — the February 2025 guide, the authority behind every reference here. Open it only to confirm something the references do not cover.

Beyond this pack: **brand.slalom.com** (Brand Hub) is the front door; the **Creative Library** holds photos, video, color bar EPS files, Adobe swatch palettes, and the "True Color" preset; the **Figma style guide** covers slalom.com's web palette and Services icon colors; the **writing style guide** and **ERG Style Guide** cover prose and ERG sub-brands.
