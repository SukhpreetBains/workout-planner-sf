# Codex: Open the Opportunity Folder

Use this guide only when the active host is Codex. Use the already confirmed absolute Opportunity path. Keep the Opportunity folder as the scope; use the Account folder only if the user explicitly chose Account-wide scope. Do not edit Codex global settings or automate its interface.

If the confirmed Opportunity folder is already the active working folder, record that and continue setup. Otherwise, guide the user:

1. In Codex, choose **File > Open Folder**.
2. Select the confirmed `<Opportunity folder>` and click **Open**.
3. Return to this setup conversation if opening the folder changes the current view. Finish setup before starting document ingestion.

Confirm whether Codex now has the Opportunity folder open. Record the answer for **Host folder access** in the readiness report and continue setup even if opening the folder is still pending. Do not report access as verified from the instructions alone.

After setup's final report, start a new conversation with that same Opportunity folder open for `workspace-add`. This gives document ingestion a fresh context while retaining access to the prepared workspace.
