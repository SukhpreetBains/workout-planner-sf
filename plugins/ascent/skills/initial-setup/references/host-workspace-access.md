# Host Workspace Access

After the confirmed Opportunity folder exists, make that folder the working location for future conversations in the active agent host. Keep setup in this conversation until the final readiness report. Do not assume that opening a folder creates a host project.

Load only the guide for the active host:

- **Codex:** [open the Opportunity folder](hosts/codex.md).

For a host without a guide, use its available folder-selection method when known. If the folder cannot be opened or verified, record the remaining user action under host workspace access in the readiness report and continue the rest of setup. A future host can be added here with its own reference without changing the shared setup sequence.
