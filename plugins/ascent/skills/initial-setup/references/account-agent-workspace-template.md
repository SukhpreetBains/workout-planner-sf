# Account Workspace Guardrails

This Account folder contains one or more Opportunity folders. Create and use an
agent `workspace/` only within an Opportunity folder beneath this Account
folder, for example `<Opportunity folder>/workspace/`.

Do not create or use a `workspace/` directory at the Account root or elsewhere
in this Account folder. Follow the `AGENTS.md` file in the selected Opportunity
folder for that workspace's rules and structure.
