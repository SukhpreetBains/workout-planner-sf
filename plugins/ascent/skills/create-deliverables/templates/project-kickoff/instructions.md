# Project kickoff template guidance

Use this template to prepare and facilitate a project kickoff, then retain the result as a living reference for the team.

## Recommended starting composition

Start with these required kickoff modules unless the user explicitly chooses a different subset:

- Title and engagement opener
- Agenda and meeting objectives
- Welcome, introductions, and team roster
- Business context
- Objectives, outcomes, and success definition
- Guiding principles
- Timeline and roadmap
- Project schedule
- Assumptions, dependencies, risks, and issues
- Stakeholder alignment and governance structure
- Meeting cadence and rhythm of business
- Immediate next steps and asks
- Closing and discussion

Offer these modules when the project needs additional context:

- Delivery approach and phase model
- High-level architecture diagram
- Epic overview

The remaining catalog modules are available when the kickoff also needs detailed scope, team, stakeholder, operating, logistics, or management-log views. Preserve the template order for any selected subset.

Treat the static example only as fictional layout guidance. Never use it as project evidence.
