# RAID log previews

These screenshots show the RAID log register built from fictional data: the
Northstar sample log and, for the source dialog, the small fictional project
used by the RAID log tests. They are visual references and do not contain
project evidence.

- `risks-expanded.jpg`: Risks tab with a row expanded and the reasoning tooltip on an assessed priority.
- `issues-overdue.jpg`: Issues tab with an overdue open item sorted first and its target date in red.
- `decisions.jpg`: Decisions tab showing "Decision made" and "Decision needed" items.
- `source-dialog.jpg`: Source dialog for a pending review item, with its evidence excerpt and document snapshot.
- `mobile.jpg`: The register at phone width.
