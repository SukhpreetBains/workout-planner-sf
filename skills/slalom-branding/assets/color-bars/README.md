# Color Bars

## Rules

- Colors always run in this order: Slalom Blue, Cyan, Coral Red, Purple, Chartreuse. Never reorder them.
- One color bar per layout.
- Never more than 20% of the layout. Scale the height off the "l" in the Slalom logo, at full or half width.
- A framing bar's solid blue line runs the full height or width of the layout, and may sit on any side.
- If the layout's background is the same color as one of the bar's swatches, change that swatch to its Dark 3 tone — Purple becomes Purple Dark 3 `#9488F0`, and so on.
- Do not change any other color in the bar.
