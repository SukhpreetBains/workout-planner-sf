# Slalom Illustrations

116 approved people illustrations across 37 subjects, from the Slalom Creative Library. One folder per subject, one SVG per variant.

## Files

- Reference an illustration by path: `assets/illustrations/<subject>/<subject>-<variant>.svg`.
- Black line-art SVGs with no color values, so they take a brand swatch cleanly.
- Most subjects ship as `skin-tone-light`, `skin-tone-medium`, and `skin-tone-dark`. The variant controls the skin fill weight, not the line work.
- `hug` pairs two figures, so its variants name both tones: `hug-skin-tone-<figure1>-<figure2>.svg`.
- `high-five` uses fill variants instead of skin tones: `high-five-black-no-fill.svg`, `-black-medium-fill.svg`, `-black-dark-fill.svg`.

Usage rules — approved colors, recoloring, illustration as accent, varying skin tones — are in [references/imagery.md](../../references/imagery.md#illustration).
