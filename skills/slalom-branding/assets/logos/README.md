# Slalom Logo

The Slalom wordmark in all four approved colors, as RGB SVGs on a `0 0 216 56.1` viewBox.

| File | Color | Use |
|---|---|---|
| `slalom-logo-blue-RGB.svg` | Slalom Blue `#0C62FB` | Default. On white, Light Gray, or a secondary-color background. |
| `slalom-logo-dark-blue-RGB.svg` | Slalom Dark Blue `#002FAF` | On white, Light Gray, or a secondary-color background. |
| `slalom-logo-white-RGB.svg` | White `#FFFFFF` | Reversed on Slalom Blue, Slalom Dark Blue, Coral Red, or dark tones. Preferred reversed color. |
| `slalom-logo-black-RGB.svg` | Black | Black-and-white layouts. |

These four are the only permitted logo colors — never a secondary brand color, never a gradient, never recolored.

Read [references/logo.md](../../references/logo.md) before placing the logo. The essentials: minimum height 0.125 in / 9 px; clear space on all sides of at least the width of an "o"; no effects, rotation, skew, pattern fills, or hybrid marks; and no new logo for any product, service, program, or team.
