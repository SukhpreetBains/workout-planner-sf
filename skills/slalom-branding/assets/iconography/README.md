# Slalom Iconography

102 approved Slalom icons, one SVG per icon, named after its label in the source library. Slalom maintains 130+ approved icons in the Creative Library; these are the set bundled with this skill.

## Files

- Reference an icon by file name: `assets/iconography/<name>.svg`.
- Each is a 305x305 viewBox line-art SVG filled with Slalom Blue `#0C62FB`. Recolor by overriding the `fill` in the embedded `<style>` block or on the `<path>` elements.

Usage rules — approved colors, circle backgrounds, sizing, never reversing — are in [references/graphic-elements.md](../../references/graphic-elements.md#icons).
