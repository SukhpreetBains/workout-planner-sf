# Typography

Source: *Slalom Brand Guide*, February 2025, pp. 40-48.

## Fonts by medium

Identify the medium before choosing a typeface — this is the rule most often broken.

- **General brand materials, including web:** Slalom Sans is the primary font. Lora is the optional supporting serif. When in doubt, use Slalom Sans.
- **PowerPoint only:** Avenir Next LT Pro, in the approved Slalom template. Avenir is *not* the same as Avenir Next LT Pro.
- **Other Microsoft exceptions:** Avenir Next LT Pro is also allowed for Outlook external-email defaults, Power BI dashboards, and editable Word documents shared with customers. Nowhere else — not social, print, video, or digital ads.
- **Fallbacks:** if Slalom Sans is unavailable, choose a clean sans-serif fallback, preserve the hierarchy, and disclose the substitution.

Both brand typefaces are bundled in [assets/fonts/](../assets/fonts/README.md) — Slalom Sans in 10 styles as woff2/woff/otf, and Lora as variable and static TTF. Self-host from there for web and digital work rather than linking an external font service, and check the README's licensing note before shipping the font files themselves to a client. With the files on hand, a fallback should be rare.

## Hierarchy

- **Headlines:** Slalom Sans Bold by default; Slalom Sans Black when the message or scale needs more emphasis; Lora Regular when it needs a softer, more humanistic read or when Slalom Sans is already heavily used.
- **Subheads:** Slalom Sans Bold or Lora Bold. Reserve all caps for short eyebrow labels above headlines.
- **Body:** Slalom Sans Light by default; Slalom Sans Regular when small sizes or busy backgrounds need more legibility.

Limit a composition to no more than three type sizes where practical.

## Setting type

- Sentence case is the standard for all communications. Use all caps sparingly — Slalom line typography, short headings, eyebrows — and never for full paragraphs. Avoid all-lowercase unless specified.
- Flush left, ragged right, always. Never justify or center Slalom Sans body copy.
- Avoid widows, orphans, and lines ending in hyphens. Make sure letters never touch.
- Set bullets one weight heavier than the text they introduce.

Leading and tracking starting points:

| | Leading | Tracking |
|---|---|---|
| Body copy | 1.1 | 0 |
| Subheads | 0.90 | 0 |
| All-cap subheads | 0.90 | 75 |
| Headlines | 0.90 | 0 |

## Quotes and captions

Two approved pairings:

- Lora Regular quote, with a Slalom Sans Bold name and Slalom Sans Regular title.
- Slalom Sans Regular quote, with a Lora Bold name and Lora Regular title.

Use curly smart quotes in image text — not slanted quotes and not straight quotes.
